### M. Zein Zulfanul Aziz

**WordPress developer & data-dashboard builder** · East Java, Indonesia

I build small things that work for people without software budgets — a price
dashboard a farmer actually opens before harvest, an invoice app for a one-person
service business. Mostly in plain HTML, CSS, and JavaScript, because a page that
answers in 300 ms beats a framework that needs a build step.

Day job: WordPress — Elementor, Bricks, JetEngine, ACF/SCF, WooCommerce. Five
years of production sites: stores, publishing platforms, and directory portals
that had to survive real traffic and real editors.

Before that I ran a one-person web studio in East Java (2017–2021), building
sites for local schools, shops, and small businesses. Six years on, several of
them are still live and still being used — which is the only review I trust.

#### How I work

- **Vanilla first.** A dependency has to earn its place.
- **Every number traceable.** If a figure is on the screen, it came from a named
  source — and imputed values are labelled as imputed, not quietly averaged in.
- **Ship small, ship working.** Then hand it to someone who will use it and watch
  what breaks.
